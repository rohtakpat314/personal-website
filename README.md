# Personal Website — Engineering Portfolio

Static portfolio site built with HTML, CSS, and vanilla JavaScript. Deployed via GitHub Pages at [rohtakpatwardhan.com](https://rohtakpatwardhan.com).

## Local development

```bash
node serve.mjs
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `index.html` — main portfolio
- `projects/` — individual project detail pages
- `brand_assets/` — images, PDFs, and media
- `serve.mjs` — local static file server
